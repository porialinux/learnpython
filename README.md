## 🚀 Getting Started

Make sure you have Python installed:

```bash
python --version
```

Clone the repository:

```bash
git clone git@github.com:porialinux/learnpython.git
```

Go to the project directory:

```bash
cd learnpython
```

Run a Python file:

```bash
python hello_world.py
```
